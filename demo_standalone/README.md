# AutoShieldX — Standalone Hardware-Free Demonstration Build

This directory contains the completely self-contained, hardware-free demonstration edition of the **AutoShieldX** automotive intrusion-detection platform.

It runs immediately without physical CAN hardware, Arduino boards, Raspberry Pi boards, MCP2515 transceiver modules, or a working Linux `can0` SocketCAN interface.

---

## 1. Data Source Disclosure & Accuracy Notice

> [!NOTE]
> **Data Transparency Notice**:
> In accordance with demonstration ethics and project documentation standards, the vehicle telemetry and security anomaly events displayed by this demonstration build are generated by an **integrated software kinematics engine** and **deterministic behavioral-event generator**. They are not physical wire measurements from a real vehicle CAN harness. The mathematical modeling, detection heuristics, and security pipeline state transitions reflect the exact logic of the real AutoShieldX C++ gateway.

## 3. Quick Startup Instructions

### Launch on Windows (Command Prompt / PowerShell)
Double-click `run_demo.bat` or run:
```powershell
python demo_standalone/demo_server.py 8080
```
Open your web browser at:
```
http://127.0.0.1:8080
```

### Launch on Linux / macOS
```bash
chmod +x demo_standalone/run_demo.sh
./demo_standalone/run_demo.sh
```

## 4. Key Functional Features

1. **Automatic ML Anomaly Increment**:
   - The **ML Behavioral Anomalies** counter starts at 0 and increments automatically every 12 seconds.
   - The increase is driven by real event generation in `demo_server.py`, which records a timestamped `ML_ANOMALY_FLAGGED` incident into `logs/autoshieldx_demo.log` and pushes it to `recent_events`.
   - The dashboard counter, live events forensics table, timestamps, and gauge meters remain **strictly synchronized**.
   - During the anomaly pulse, the SW-420 Road Vibration gauge jumps to `3.42 G` (triggering the `> 3.0 G` ML threshold) and then smoothly returns to baseline road vibration.

2. **Continuous Vehicle Telemetry (20 Hz)**:
   - Speed accelerates realistically up to cruising speed (60–95 km/h).
   - RPM calculates dynamically using a 5-speed transmission gear simulation.
   - Engine coolant temperature warms from 25°C to 90°C and stabilizes with thermostat oscillation.
   - Steering angle and wheel speed follow realistic highway lane dynamics.

3. **Replay Feature Cleanly Removed**:
   - The Replay Detections card has been removed from the KPI display.
   - The underlying zero-trust pipeline architecture (Payload Validation, HMAC-SHA256, Replay Monotonic Protection, and ML Anomaly Detection) remains fully described in the pipeline flow panel.

4. **Android Companion App Support**:
   - The server emits UDP packets on port `16000` to `127.0.0.1` and `10.0.2.2` (Android emulator loopback).
   - The Android companion application also polls `http://10.0.2.2:8080/api/status` automatically, allowing both the web dashboard and mobile app to display synchronized live telemetry.
